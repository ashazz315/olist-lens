# v2.1 本机全流程验收（2026-11-18）

业务前台和管理后台共用本机 Node 后端与原生 **PostgreSQL 18.6**。验收使用独立合成历史回放，沿用 `operations-2.0.0`、`monitoring-2.0.1`、原计算阈值及现有审批、任务、发布 SQL。CloudBase 服务凭证读取返回 401（已过期），本次本机适配器在隔离目录执行原 PostgreSQL 迁移。任务记录来自浏览器及 HTTP 验收操作，保留管理员与业务用户身份。

原有平台定向回归 **19/19**。本机嵌入式 WASM PostgreSQL 曾出现内存错误，最终验收使用原生 PostgreSQL。首次关闭过程由 `pg_ctl` 执行干净停库，之后在新进程重新登录并完成下载。Excel 文件首次独立读取时 Windows XML 加速器抛出 `SystemError`，纯 Python XML 路径完成内容核对。历史真实全量计算故障仍未解决，本轮验收范围为模拟回放。

浏览器全链路使用首版回放快照。后续将集中场景的数据生成器更新为版本 2，活动结束或商品退出后，把对应活动的花费和归因计数归零，并保留渠道层面的其他付费访问。版本 1 输入仍可校验。版本 2 定向测试实际通过两个活动分支、正付费渠道访问及原全店金额告警。已保存的验收快照与下载文件作为首版证据保留。

在 `v21/platform`运行 `./Start-local-replay.ps1 -AcceptanceRun 2026-11-18T08-25-03-621Z` 可以打开原验收库，默认端口 **8794**。前台 `/`，后台 `/admin/`。用户名为 `local-admin` 和 `local-analyst`，对应密码仅见验收目录的 `local-accounts.json`。新工作树使用 `npm ci` 安装固定本机依赖。模拟调度按配置的一次未来时刻执行，服务离线期间到期的未完成任务会在开启后由回放循环检查。缓存报告和账号文件仅在私有目录保留。
