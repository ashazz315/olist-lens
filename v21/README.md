# Olist Lens v2.1 本机调查工作区

日期：2026-11-15（Asia/Shanghai）。这是隔离工作副本中的可执行预验收版本，未部署、未提交 GitHub、未合并 PR。原项目及原始数据保持只读。

## 启动

在 PowerShell 运行本目录 `Start-v21.ps1`，访问 http://127.0.0.1:8791 。启动器使用本轮取得成功回执的 Node 26.4.0 路径；同解释器后来仍出现访问冲突，**不能视为稳定性已验收**，详见 [测试报告](docs/TEST_REPORT.md)。可用 `LENS_NODE_EXE` 指向另一台机器上经过单独验证的同版本解释器。首次准备来源时，在服务停止状态、工作副本根目录运行 `node v21/import-m0.cjs`（明确使用相同解释器）；此命令只由人工执行，不建立后台计划。

默认来源为相邻 `olist-stage3` 工作区的已存在 M0 数据。`LENS_SOURCE_ROOT` 可指定原项目目录，`LENS_RUNTIME_DIR` 可指定新的独立运行目录。原三表及外部 CSV 均复制后处理。当前数据不再只存浏览器：本新增工作区使用本机 Node SQLite；旧版 `/legacy/` 的浏览器 IndexedDB 保持独立，不自动迁移或合并。

## 使用路径

1. 数据与版本：读取 M0 或手工上传完整 CSV + manifest；校验、复算后确认发布。
2. 经营总览：查看两个完整周、八周基线、异常事件及负向商品金额贡献。
3. 点击商品：查看金额/数量/价格分解、历史趋势及五维诊断状态。关联订单履约按 distinct order_id，评价明确为关联订单评价。
4. 独立数据探索：分别查看零售库存、销售、广告活动周。禁止将这些数据拼到 Olist SKU。
5. 从已发布事件建立调查，填写负责人；查阅版本绑定的 E1–E5 证据包。人工审核、行动、执行与效果复核各有独立门禁。
6. 没有行动后真实新数据，保持 verification_pending / unverified，不关闭，不宣称改善。

## 模型和 GA4

目前没有真实模型报告，页面显示“模型未连接”。独立适配器仅在服务端配置 `LENS_MODEL_API_KEY`、`LENS_MODEL_NAME` 后启用，`LENS_MODEL_URL` 可指定 HTTPS OpenAI-compatible chat completions 地址。密钥不写文件、不从其他项目复制、不下发浏览器。首次配置后，建立调查会发起真实模型请求；证据将发送到所配置的提供商。结果仍需人工语义复核。生产提供商连通性和能力尚未验收，测试中的 mock 不算真实 LLM。

GA4 状态接口已存在，Google 应用凭据只表示“配置待核验”，不等于连接成功。尚无 BigQuery 授权、实际导出或查询执行器。不能显示真实流量、漏斗转化率。GA4 商家也不是 Olist，授权后仍须独立命名空间。
