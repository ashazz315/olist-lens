# 功能清单与证据边界

| 能力 | 实现状态 | 验证范围 |
|---|---|---|
| 原 v1 履约/体验、v2 operations/monitoring | 保留原代码；新界面调用原引擎 | 原 44 回归测试及真实下降周期 SQL/JS 门禁；不代表阶段三独立 Python 全量完成 |
| CSV 导入、候选确认、版本修订、失败保留与重试 | 已实现 | 真实 M0 导入；内部失败/重复/事务/恢复测试 |
| 原监控事件去重与来源版本 | 复用 monitor-store | 真实同批重复不新增事件；原规则未改 |
| 商品贡献榜与数量/价格分解、历史趋势 | 已实现 | 真实全店变化与商品合计一致；原引擎测试 |
| SKU 履约与关联订单评分 | 已实现 | distinct 订单、最新评分、日期分母、同源交运补充；无单品因果声明 |
| 库存/销售/广告独立探索 | 已实现，limited 数据质量 | 真实行数、字段、负库存、区间兼容性；不跨商家 JOIN |
| GA4 流量与转化 | 接口状态和缺口已实现 | 未授权、未下载；没有真实 CVR 或渠道表现 |
| AI 调查/追问、十区报告、证据引用 | 独立服务适配器和界面已实现 | 断连与 mock 契约通过；真实模型调用尚未验证 |
| 人工任务、审核、原因、行动、执行、重开、附件 | 已实现 | 自动化隔离 UI 交互和状态门禁；不是业务审核人签署 |
| 效果复核和人工关闭 | 实现条件门禁和非因果快照对比 | 后续数据成功路径仅内部合成测试；真实数据缺失时未验证并阻断关闭 |
| 导出与刷新持久化 | 已实现 | 新工作区 SQLite 持久化；原 IndexedDB 继续独立存在 |
| 身份认证、云共享、多人权限、自动采集/调度 | 未实现 | 本机单用户自报身份；无云端部署 |
| 库存利润、库存预测、广告 CTR/CPC/ROAS 重算 | 不提供 | 证据不足，不能以原报告值或填零代替 |

正式展示只使用已获取历史文件。内部合成数据存临时测试目录；浏览器验收用真实文件但人工操作记录明确标为自动化 QA，保存在独立 evidence/browser-*/isolated-qa-workspace，未进入正式 runtime 的行动记录。
