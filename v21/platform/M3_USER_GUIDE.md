# M3 本地候选版使用与回滚

本文件对应隔离开发副本。**尚未云端发布，真实全量重新计算门禁未通过。**

## 启动

在本目录运行 `./Start-platform.ps1`。启动器固定 Node v24.22.1，读取被 Git 忽略的 `private/config.json`，配置本机 Python 与报告运行时。前台 `http://127.0.0.1:8792/`，管理后台 `http://127.0.0.1:8792/admin/`。

只有启动成功后上述地址才可访问。不要将 `private/`、运行时原始数据或服务密钥打包到静态托管。该地址不是云部署地址。

## 管理员

1. 用应用账号 `zhang` 登录；初始密码只保存在本机 `private/initial-admin.json`，不在报告或聊天展示。
2. 在“数据导入”选择真实工作区和 Olist。可选择已审计 Kaggle V2 九个原始 CSV，或原有标准三表；填写真实来源 manifest（可参考 `private/baseline/olist/version.json` 的 `manifest` 部分）。九表当前只接受与既有审计一致的固定文件哈希。
3. 逐文件上传到私有存储后创建任务；断线重传会复用内容哈希对象，不覆盖源文件。同一数据集只能有一个活跃任务。
4. **目前不要发布本轮失败批次。** 已上传批次留下门禁日志并取消排队；修复计算运行环境后，可在任务中重试。新候选只有质量、独立计算与保存均通过才进入待确认。发布要求管理员及当前版本比较条件，不得手改数据库指针绕过检查。
5. “AI 模型配置”可设置 Provider、Base URL、模型及参数，API Key 留空保留已有密钥。保存不等于连接成功；点击“测试已保存连接”验证实际接口。不要把密钥粘贴到聊天或源文件。无密钥时使用明确标记的规则诊断。

## 业务用户

- 登录后选择“真实历史”查看原已验证的 Olist 版本；GMV 指购买订单商品金额，不是企业实际净 GMV。
- 从负向贡献商品进入 SKU 详情，核对销量、价格分解和证据。营销/流量/转化/库存无共同业务数据时显示缺口；选择“独立模拟”可演练这些维度，不能解释为 Olist 真实数据。
- 调查报告需要人工复核；行动、执行记录和后续复核保持原有流程。历史快照不能证明现在执行的措施带来改善。
- 在“报告中心”下载 PDF、Excel 或 JSON。导出只包含选定工作区当前不可变版本及相同版本任务；发布发生切换时先刷新后导出。

## 本轮回滚状态

- 应用未部署、旧公开版本未替换，因此不存在需要回滚的新线上应用。
- 九表只新增私有不可变文件及一个取消的批次；原有效版本指针未变化，不需要数据回滚，也不删除新增审计证据。
- 后续若管理员发布新的有效版本后需要恢复，继续使用已有 `POST /api/v1/restore`，提交旧 `version_id`、当前 `expected_current` 和具体 `reason`；服务端权限与原子比较必须保留。
- 发布前必须取得实际旧服务构建/镜像/配置备份和可执行回滚目标。本轮未确认 `olist-lens` 云托管服务存在，因此不能提供虚构的镜像回滚编号。

## 运行限制

Node24 全量 SQL 计算仍失败，转换器另有访问冲突；不降低质量门槛。Excel 本机使用 Codex artifact-tool，PDF 依赖 reportlab 与 `LENS_PDF_FONT` 指定的可嵌入中文 TTF（默认本机 Deng.ttf）；云端运行时尚未打包验收。服务端密钥需长期可轮换，当前开发凭证不能直接作为生产配置。GA4 未授权，真实模型尚未连接；无后台采集或定时任务。
